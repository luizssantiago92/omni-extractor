# Security Policy

## Reporting a vulnerability

Report security issues privately through [GitHub Security Advisories](https://github.com/luizssantiago92/omni-extractor/security/advisories/new).

Do not open a public GitHub issue for a suspected vulnerability.

Include the extension version, the Chrome version, and steps to reproduce. If you can, describe the impact (for example, which sites or stored datasets an attacker could reach).

## Scope

This policy covers the Omni Extractor Manifest V3 extension in this repository: the side panel, the service worker, the content script, and the local data table.

Out of scope: vulnerabilities in Chrome itself, and issues that require the user to load a modified unpacked build.

## What to expect

There is no bug bounty. We will acknowledge the report and work on a fix for the current version on `master`.

## Supported versions

Security fixes apply to the extension version currently on the default branch.
