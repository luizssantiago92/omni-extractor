# Omni Extractor

Chrome extension (Manifest V3) for extracting structured data from web pages.

## Current slice (v0.3.0)

- Skills: `omni-sidepanel-ui-polish` (S-0001) + `omni-list-extractor-engine` (S-0002)
- Premium side panel: Syne + Instrument Sans, green/gold system, segmented nav, motion
- Brand: gold **O** + six extraction arms
- List Extractor engine + Data table CSV
- Responsive to side-panel width

Deferred: settings, notifications, tool chrome (info/favorite/refresh/close).

## Load unpacked (local Chrome)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select the `extension/` folder in this repo
4. Click the Omni Extractor icon (or pin it) to open the side panel
